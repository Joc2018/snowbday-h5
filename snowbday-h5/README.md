# snowbday-h5 · 给你的小小宇宙

给朋友的生日祝福 H5。手机优先，微信扫码可直接打开。每一轮迭代的成品都提交到本仓库。

## 在线地址

`https://joc2018.github.io/snowbday-h5/`

首次使用请在仓库 `Settings → Pages → Build and deployment` 中选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后等 1–2 分钟生效。之后用这个 HTTPS 链接生成二维码即可，不依赖任何本地电脑。

## 四幕

| 场景 | 内容 |
| --- | --- |
| intro | 星空开场 |
| cake | 许愿吹蜡烛：点击烛火，或授权麦克风后吹气 |
| carousel | 旋转木马相片灯：自动旋转、拖动带惯性、点击照片放大 |
| letter | 最后一封信 |

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构、文案、照片引用 |
| `style.css` | 全部视觉（含旋转木马的顶棚 / 中柱 / 底座 / 相框） |
| `app.js` | 场景切换、吹气感应、旋转与拖动、照片放大 |
| `assets/photo-1.svg` … `photo-6.svg` | 六张占位图，换成自己的照片即可 |

纯静态，无构建步骤、无框架、无 CDN、无外部字体。所有资源都是仓库内相对路径，没有写死任何电脑磁盘路径。

## 换成自己的照片与文案

1. 把 `assets/` 里的 6 个占位文件替换成 JPG/PNG（保持文件名最省事：直接覆盖并在 `index.html` 中把 `.svg` 改成对应扩展名）。
2. 收件人称呼、正文、署名日期在 `index.html` 的 `scene--letter` 段。
3. 照片说明文字在 `index.html` 的 `figcaption` 与 `data-caption`。

## 素材与署名

旋转木马相片灯的视觉灵感来自 `Joc2018/carousel-lamp`（**Carousel Lamp · 旋转木马相片灯，作者：咕噜蛋Daria。仅限非商业使用，必须保留作者署名及许可说明**）。夜色配色、丝带标题、暖光灯泡、花纹顶棚的氛围参考该项目；本页的顶棚、中柱、底座、相框、丝带均为 CSS 与 SVG 重新绘制，未复制其代码，也未使用其 `public/*.png` 位图素材（四张贴图合计约 9.5 MB，会让手机微信加载明显变慢）。`ASSETS.md` 为该素材包的清单说明；若后续要 1:1 使用原贴图，需先压缩再加入。
