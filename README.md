# snowbday-h5 · 给你的小小宇宙

给朋友的生日祝福 H5。手机优先，微信扫码可打开。每轮迭代都提交到本仓库。

## 现在的流程（四幕）

1. **吹蜡烛** — 点击烛火，或授权麦克风后吹气
2. **旋转木马相片灯** — 原版 Carousel Lamp 3D 场景，可上传自己的照片
3. **花火大会** — canvas 绘制的盛大烟花，可点「再放一束」
4. **祝福信** — 点击粉色信封，蜡封碎裂、信封翻开、信纸丝滑抽出；烟花延续不中断

幕与幕之间用统一的 **3D 运镜转场**（景深推拉 + 缩放淡入），不再硬切。

## 怎么打开（重要）

不要直接双击 `index.html`。`file://` 协议下，浏览器会因安全策略拦截 ES module 与 iframe（表现为打不开、或报 `Indexed Database API is denied`）。必须用本地 HTTP 服务：

**Windows 一键：** 双击仓库里的 `启动预览.bat`，浏览器会自动打开 `http://localhost:8899`。

**或命令行：**
```bash
cd 本目录
python -m http.server 8899
# 浏览器打开 http://localhost:8899
```

**上线（手机/微信扫码）：** 仓库 `Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save`，1–2 分钟后 `https://joc2018.github.io/snowbday-h5/` 生效，用它生成二维码。

> 已做兼容：即使 IndexedDB 被禁用，3D 场景照常加载；照片会降级存到浏览器 localStorage 的预览图，刷新后仍在。

## 改文字（全部可自定义）

打开 `app.js`，最顶上的 `COPY` 对象里集中了**所有文案**：蜡烛页、花火页、信的日期/称呼/正文/署名、信封上的英文等。改引号里的文字即可，正文 `letter.lines` 是数组，一行一段。改完刷新生效。

## 改照片

`carousel.html` 页面里点「＋ 挂相片」即可在浏览器里上传替换，照片只存在当前设备，不上传服务器。优先存到 IndexedDB；若微信内置浏览器禁用 IndexedDB，则自动降级用 localStorage 保存预览图。照片会一直保留到下次手动更换/取下，不会自己消失。（`assets/photo-*.svg` 是早期自制版的占位图，当前原版相片灯不使用它们。）

### 换设备也能看到同一批照片（免费，不需云服务）

1. 在原来设备的旋转木马页点「＋ 挂相片 → 导出照片包」，得到 `snowbday-photos.json`。
2. 用微信把这个文件发到「文件传输助手」或另一台设备。
3. 另一台设备打开同一个生日网站，进入旋转木马，点「＋ 挂相片 → 从照片包导入」。
4. 两台设备就是同一批照片了。以后原设备再改照片，重新导出并导入一次即可。

这是**手动迁移**，不是自动云同步；不耗云服务资源点。若要自动同步，需要开通 WorkBuddy 云服务并加入登录，这会产生资源点消耗。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 四幕结构、信封/信纸节点 |
| `style.css` | 全部视觉：星空、蜡烛、3D 转场、信封开信动画 |
| `app.js` | 文案配置、场景流程、转场调度、烟花引擎 |
| `carousel.html` | 独立相片灯页（iframe 嵌入第二幕） |
| `carousel-lamp.js` | 原版 Three.js 场景打包产物 |
| `carousel-app.css` | 相片灯界面样式 |
| `carousel-heic.worker.js` | HEIC 图片解码 worker |
| `carousel-assets/` | 原版贴图、字体、Happy birthday 花体标题 |
| `启动预览.bat` | Windows 一键本地预览 |

纯静态，无构建、无框架、无 CDN。资源均为仓库内相对路径，无写死磁盘路径。

## 相片灯署名（重要）
